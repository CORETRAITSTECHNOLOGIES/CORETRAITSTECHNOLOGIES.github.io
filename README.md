# Samarth Golwalkar — Engineering Portfolio

Live website: https://coretraitstechnologies.github.io/

Dark responsive, static HTML/CSS portfolio for RISC-V, RTL, FPGA, ASIC learning and automotive embedded systems.

## Pages
- `index.html` — Home, experience, projects, interests, contact
- `projects.html` — Selected projects and verified GitHub repository links
- `assets/style.css` — Theme and layout
- `404.html` — Missing page

## GitHub Pages
1. GitHub repository: `CORETRAITSTECHNOLOGIES/CORETRAITSTECHNOLOGIES.github.io`
2. Go to Settings → Pages → Build and deployment → Deploy from a branch.
3. Select `main` and `/ (root)` and save.
4. Browse to https://coretraitstechnologies.github.io/

## Editing
Edit the HTML text and CSS, commit to `main`, and GitHub Pages will redeploy. Verify project details and update content as projects evolve.
